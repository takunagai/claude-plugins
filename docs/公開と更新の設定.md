# 公開と更新の設定

確認日: 2026-11-08

## 公開範囲

- リポジトリ `takunagai/claude-plugins` は **public**（2026-11-08 ユーザー判断）。カタログのみを置く
- 載せるツールのリポジトリが非公開でも、カタログ側にリポジトリ名が載る。載せる前に確認する

## 名前の決定

- マーケットプレイス名: `takunagai`。利用者は `<プラグイン名>@takunagai` で入れる
- プラグイン名: ツールのリポジトリ名・CLI のコマンド名と同じ。ツール側 `plugin.json` の `name` と一致させる
- 公開後に変えると既存のインストールが壊れる。変えるときは `marketplace.json` の `renames` を使う

## version を書かない理由

エントリにも `plugin.json` にも `version` を書くと、値を上げるまで利用者に更新が届かない。省略するとコミットごとに届く。

## 検証状況

- `claude plugin validate .` は通る。ただし `github` ソースの `repo` の誤りは見つからないため、追加後は実際にインストールして確かめる
